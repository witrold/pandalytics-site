# Pandalytics — page du projet

Page publique de **Pandalytics**, un assistant de bureau Windows pour League of Legends : profils joueurs, statistiques de champions, tierlist, aide à la draft et tableau de la partie en cours.

- Projet personnel, gratuit et non commercial.
- Site : https://witrold.github.io/pandalytics-site/
- Téléchargement : [dernière version (v0.1.1)](https://github.com/witrold/pandalytics-site/releases/latest)

## Contenu de ce dépôt

- `index.html` : la page d'accueil.
- `PRIVACY.md` : politique de confidentialité.
- `TERMS.md` : conditions d'utilisation.
- `riot.txt` : fichier de vérification du produit auprès de Riot Games.

Le code source de l'appli n'est pas publié ici.
